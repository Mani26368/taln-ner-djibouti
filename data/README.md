# Données

À compléter :
- **Source** des textes (public, synthétique ou anonymisé).
- **Nombre** de textes / phrases annotés.
- **Types d'entités** : ORG (institution), LOC (lieu), FORMATION, DATE, PER (personne).
- **Annotation** : qui a annoté, comment (format : `(début, fin, type)` par entité).
- **Séparation** : quelles phrases servent à construire les règles, lesquelles servent à tester (le test ne doit pas servir à écrire les règles).
- **Limites** : taille réduite, un seul annotateur, etc.
